## Key Themes for Joe

### 1. Cost efficiency is the new battleground
- Anthropic added rate limits to curb Claude Code heavy users (mid-2025)
- Token efficiency matters: wasted runs = wasted money
- Tools that get it right first pass are winning

### 2. Agentic coding is mainstream
- Claude Code, Codex, Cursor are now **autonomous multi-file agents**, not just autocomplete
- They understand repos, run tests, iterate with minimal input
- This directly benefits Joe's vibe-coding workflow

### 3. Context windows keep growing
- Claude Sonnet 4.6 and Opus 4.6: 1M token context window (beta)
- This means entire codebases can fit in context — huge for CoinUsUp, Even Us Up

### 4. Free/cheap options are stronger than ever
- **Antigravity** (free preview): access to top models free — worth trying
- **Gemini CLI**: solid free tier, good for quick tasks
- **Codex**: still strong for code generation in OpenClaw stack
