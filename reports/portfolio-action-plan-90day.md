You have 4 active projects and high income concentration risk (consulting = 90%+ of revenue). This plan de-risks by:

1. **Running 3 tight monetization experiments** (CoinUsUp paywall, Even Us Up retention, Signal App paid pilots) — parallel, 4–6 weeks each
2. **Productizing your top consulting outcome** into a $2.5K/mo retainer with 1–2 pilots by April
3. **Implementing weekly metrics tracking** to stay on top of all projects (15 min/week)

**If all 3 experiments succeed:** You'll have $15K–$20K MRR and clearer signals on which products deserve continued investment.

**If 1–2 experiments fail:** You'll know fast, and consulting retainer backs you up while you iterate.

## 60-Day Review (Apr 17 – May 16)

### Decision Checkpoints

**CoinUsUp Paywall:**
- **Success:** ≥5 paid users, ≥1% conversion → ship as default; iterate pricing
- **Partial:** 2–4 paid users, <1% conversion → lower price to $4.99/mo; test new messaging
- **No traction:** <2 paid users → pause monetization; focus on growth first

**Even Us Up Retention:**
- **Success:** 7-day retention ↑25%, referral rate ≥0.5/group → ship retention loop; plan premium tier
- **Partial:** 7-day retention ↑15%, referral stalled → retention works; test referral incentives
- **No traction:** retention flat, no referrals → pivot to different feature (notifications? templates?)

**Signal App:**
- **Success:** 10–25 pilots, ≥60% accuracy, ≥80% retention → expand to full launch; add 2nd tier
- **Partial:** 5–10 pilots, 50–60% accuracy → iterate signal model; extend pilot
- **No traction:** <5 pilots, accuracy <50% → pivot niche or indicator; try again with different asset

**Consulting Retainer:**
- **Success:** Pilot client happy, hours match estimate → pitch to 5 warm leads at full price ($2,500/mo)
- **Partial:** Pilot running but hours 50% over estimate → reduce scope or increase price
- **No traction:** Pilot canceled or client unhappy → pick different outcome to productize

### Actions (Weeks 5–8)

Based on checkpoint results:

**CoinUsUp:**
- If success: Scale paywall, test $14.99/mo premium tier
- If partial: Launch A/B test (current messaging vs. new positioning)
- If failed: Pause monetization; focus on acquisition (growth experiments instead)

**Even Us Up:**
- If success: Ship sticky features + referral incentives; plan premium tier ($2.99/mo)
- If partial: Add notifications; test referral incentive (skip 1 settlement = $5 value)
- If failed: Pivot to different sticky feature (templates? recurring groups?)

**Signal App:**
- If success: Open public waitlist; plan expansion (2nd asset + premium tier $99/mo)
- If partial: Adjust signal model; continue pilot with adjusted pricing/features
- If failed: Pause Signal App; allocate resources to stronger experiments (CoinUsUp or retainer)

**Consulting Retainer:**
- If success: Pitch to 5 warm leads; target 2 new clients by May 31 ($5K/mo MRR)
- If partial: Adjust scope; document updated SOP; retry with same client or next prospect
- If failed: Pick outcome #2 from your list; design new retainer

### Metrics (Weeks 5–8)

## Key Success Principles

1. **One experiment per project.** You're not multi-tasking; you're running focused tests.
2. **Weekly metrics, not daily obsession.** 15 min/week is enough; more is burnout.
3. **Fail fast.** If an experiment shows no traction by week 4, pivot or pause.
4. **Consulting retainer is your hedge.** It protects income while you test products.
5. **Celebrate progress, not perfection.** Even one $500/mo product revenue is a win.
