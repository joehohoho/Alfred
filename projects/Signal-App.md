## 🎯 Market Opportunity

**Market Size:** 50k-500k retail traders globally (Canadian market alone: 10k-20k active)

**Key Problem:** Retail traders get signals from 5-10 sources but lack:
- Unified position sizing guidance
- Risk assessment (portfolio correlation, VaR)
- Backtesting against personal risk profile
- Centralized signal management

**Competitors:**
- TradingView Signals (basic)
- Binance Signal Bot (crypto-only)
- TradeTerra (premium, expensive)
- Signal aggregators (exist but lacking analysis layer)

**Joe's Angle:**
- Direct trading experience
- Signal filtering + analysis expertise
- Risk-aware position sizing (unique)
- Backtesting engine

## 🎯 Feature Roadmap

### Phase 1: Core Signal Aggregation (MVP)
- Import from 5-10 signal sources (TradingView, Binance, Discord, email)
- Unified signal feed (unified UI + filtering)
- Basic backtesting (test signals against 1-year history)
- Estimated effort: 6-8 weeks

### Phase 2: Risk Analysis (Differentiation)
- Portfolio correlation analysis
- Position sizing recommendations
- Value-at-Risk (VaR) estimates
- Estimated effort: 4-6 weeks

### Phase 3: Backtesting Engine (Productization)
- Test trading strategies against 5-year history
- Monte Carlo simulation
- Performance metrics (Sharpe ratio, max drawdown)
- Estimated effort: 6-8 weeks

### Phase 4: Go-to-Market
- Public launch vs. keep as internal tool (decision pending)
- Pricing: $29-79/month tiers
- Marketing: Reddit, Discord, TradingView communities
