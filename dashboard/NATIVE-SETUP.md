# Game Mode Widget — Direct Dashboard Setup (No Extension Required)

## Option 1: Bookmarklet (Easiest)

Create a bookmark in Chrome that injects the widget when clicked:

1. **Create the bookmark:**
   - Right-click the Chrome bookmarks bar
   - Select "Add page" 
   - Title: `Game Mode Widget`
   - URL: Copy the code block below ↓

2. **Paste this as the URL:**

## How to Use

**Active (Green):** Click "Pause" to pause all work agents

**Paused (Orange):** Click "Resume" to resume all work

The state updates every 2 seconds. All work is queued and resumes where it left off.

---

## Preference

**Bookmarklet** is easiest if you use the dashboard regularly — just click it once per session.
**Console** is quick if you just need it once.
