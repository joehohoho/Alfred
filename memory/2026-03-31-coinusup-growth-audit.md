## Detailed Findings

### UX Friction Analysis

**Friction Point #1: Onboarding Clarity**
- Issue: New users unclear on roommate vs. travel modes
- Current: No guided selection, users may choose wrong mode
- Impact: If mode is wrong, entire expense split logic breaks
- Fix: Wizard-style selection, examples, mode can be changed later
- Timeline: 4-6 weeks (includes user testing)

**Friction Point #2: Expense Entry**
- Issue: Two entry paths (manual + OCR) not unified
- Current: Users may not know OCR exists; if OCR fails, they abandon
- Impact: Manual entry is friction; users expect easy receipt scanning
- Fix: Single unified entry flow, OCR as enhancement with graceful fallback
- Timeline: 3-4 weeks (UX redesign, error handling)

**Friction Point #3: Settlement**
- Issue: Interac e-Transfer is Canada-specific, may confuse users
- Current: No education on why Interac, how long clearing takes
- Impact: Users expect instant settlement like PayPal/Venmo
- Fix: Clearer settlement UI, expected clearing time (24-48h), education
- Timeline: 2-3 weeks (UI tweaks, messaging)
