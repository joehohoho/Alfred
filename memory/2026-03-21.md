## Key Design Decisions

1. **Quality-gated capture:** Capture button only enabled at 75%+ quality score
   - Reduces OCR failures
   - Improves user confidence
   - Clear visual feedback

2. **3-step split flow vs. single-page:**
   - Reduces cognitive load
   - Mobile-friendly (smaller screens)
   - Clear progression: review → assign → confirm
   - Allows backtracking for adjustments

3. **Item-level confidence:**
   - Low confidence items highlighted
   - Per-item editing support
   - User can validate before committing
   - Builds trust in system

4. **Camera control accessibility:**
   - Feature detection prevents crashes
   - Graceful fallback to manual entry
   - Emoji icons for quick recognition
   - Tooltips for clarity

5. **Assignment flexibility:**
   - Quick "all to member" buttons for speed
   - Per-item assignment for precision
   - Smart distribution helpers (round-robin)
   - Multiple split modes supported (AMOUNT, PERCENTAGE)

**Challenges:**

- Quality feedback (confidence scores) significantly improves UX trust
- Confirmation step ("review before creating") reduces user regret
