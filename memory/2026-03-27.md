## 🔬 Research Completed

### Canadian Payment Infrastructure

**Interac Direct:**
- API-driven auto-deposit (no security questions required)
- Available through most Canadian banks
- Natural UX for Canadian users (familiar from banking apps)
- Perfect for household settlement use case

**Provider Evaluation:**
1. **VoPay** ✅ RECOMMENDED
   - Cost: $0.25-0.75 per transaction + $50/mo setup
   - Setup time: 2-4 weeks
   - Canadian focus, well-documented, sandbox available
   - Handles compliance reporting

2. **Paysafe** 
   - Cost: $0.50-1.00 per transaction + $100/mo
   - Setup: 4-6 weeks
   - Enterprise-grade, more features than needed (overkill for MVP)

3. **Direct Bank Integration**
   - Cost: $0.25-1.50 per transaction
   - Setup: 6-12 weeks
   - Full control, but high initial cost + complexity

**Compliance Requirements:**
- **FINTRAC:** Know Your Customer (KYC), transaction reporting for >$10k
- **PIPEDA:** Privacy, consent, right to access/delete data
- **PCI-DSS:** NOT required for Interac Direct (no card data)
- **Personal Use Exemption:** Likely applies for household groups (low-risk MVP)

## 💡 Key Decisions

| Decision | Rationale |
|----------|-----------|
| **3-Phase Rollout** | MVP (manual confirm) → Phase 2 (VoPay auto-send) → Phase 3 (premium tier). Reduces complexity, launches faster, validates demand. |
| **Email-Only KYC for MVP** | Faster build (1-2 weeks vs 4 weeks for full KYC). Lower compliance risk. Full KYC in Phase 2 if needed. |
| **Manual Confirmation in MVP** | No API integration required. Still better UX than Splitwise (zero external settlement). Webhook integration comes Phase 2. |
| **VoPay for Phase 2** | Canadian-first, cost-effective, well-documented. Easy to integrate. Fallback if issues. |
| **Free MVP → Premium Phase 3** | Build user base + gather feedback first. Monetization after product-market fit. Reduces revenue risk. |
| **Webhook Stub (Phase 1)** | Prepare for VoPay integration without coupling to Phase 2. Clean separation of concerns. |
