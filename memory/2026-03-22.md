### Technical Insights

**What Makes This Feasible:**
- Stripe API v2025 (latest) fully supports subscriptions + dunning
- Supabase Functions give direct Stripe + DB access
- RLS is set up for security (org admins manage, webhooks bypass via service_role)
- Checkout session flow already proven in app subscriptions

**Key Dependencies:**
- Stripe Webhook Signing Secret (get from dashboard)
- Email templates (use existing `email_templates` table)
- Cron (if doing scheduled win-backs; Stripe webhooks handle most)

**Risks & Mitigations:**
- ❌ Webhook failure → subscription created in Stripe but not tracked in DB
  - Mitigation: Stripe dashboard shows all subscriptions; can manually sync if needed
- ❌ Race condition: checkout success before webhook fires
  - Mitigation: Webhook is authoritative; UI should poll subscription status
- ❌ Dunning emails not sent
  - Mitigation: Falls back to Stripe's default retry, or cron job as fallback
