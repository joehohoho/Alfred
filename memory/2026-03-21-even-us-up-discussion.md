# Even Us Up Differentiation Strategy — 2026-03-21 20:03 ADT

## Discussion Topic
How does Even Us Up win against Splitwise and similar apps? What features make users switch and stay?

## Core Insight
**Don't try to out-Splitwise Splitwise.** Even Us Up should own settlement (the actual job-to-be-done) rather than just tracking expenses.

Most users don't want ledgers—they want *closure*. Splitwise tracks well; settlement still feels manual and socially awkward.

## Three Killer Differentiators

### 1. Instant Settlement Orchestration
**Features:**
- "Settle this group now" button with minimum-transfer optimization (N debts → fewest payments)
- Auto-generated personalized payment requests + links per member
- Smart nudges for non-payers
- "Close group" mode with zero-balance verification

**Why users switch:** Settlement feels manual and awkward in Splitwise  
**Why they stay:** Even Us Up becomes the fastest path from "messy expenses" → "done"

### 2. Receipt-First + Chat-Native Capture
**Features:**
- Snap receipt → OCR extracts items, taxes, tip, currency
- Parse from chat screenshots / forwarded text ("I paid $86 at Moxies for 4 ppl")
- Suggested split modes (equal, itemized, couples, custom weights)
- Draft expense inbox with one-tap confirmation

**Why users switch:** 60-second logging instead of 5-minute manual entry  
**Why they stay:** Habit forms because capture is painless

### 3. Fairness Engine (Real Relationships)
**Features:**
- Rule-based group profiles: roommates, couples, family, trip crew
- Persistent fairness rules: % income-weighted, alternating categories, special cases
- Explainability: "Why does Alex owe $42.18?" with transparent calculation steps

**Why users switch:** Better reflects real-world fairness; fewer disputes  
**Why they stay:** High switching cost once rules are set + trusted

## Key Risks to Mitigate

1. **Feature bloat before wedge clarity** — pick one killer workflow first (e.g., trip closeout in <3 min)
2. **Trust/math errors** — ledger immutability, audit trails, transparent recalculation logs
3. **Settlement dependency risk** — multi-rail design (native transfer links, manual fallback, payment-agnostic)
4. **Cold-start friction** — no-account guest links, web settle pages, SMS/email deep links

## Top 3 Actionable Recommendations

### Rec 1: Build "Trip Closeout in 3 Minutes" Flagship Flow (90-day priority)
**Scope:**
- Create trip → add expenses (OCR + quick add) → one-tap optimized settlement plan → send payment requests → closeout dashboard
- Success metric: median time from last expense to "all settled" < 72 hours

**Why first:** High-intent, high-pain moment; users actively seek better tools and invite others

### Rec 2: Launch Zero-Install Participant Experience
**Scope:**
- Guest links for viewing balance + confirming payment (no signup)
- Lightweight web settlement page
- Frictionless reminders via share sheet/SMS template
- Deferred account creation

**KPIs:**
- Invite-to-first-action rate
- % non-registered participants completing payment
- Group completion rate

**Why:** Network products die on invite friction; this removes biggest growth bottleneck

### Rec 3: Productize Trust ("Explain Every Cent")
**Scope:**
- Per-expense change history (who/when/what)
- Deterministic rounding policy displayed in-app
- "Balance explanation" panel for every user
- Dispute workflow: propose correction + recalc preview before commit

**KPIs:**
- Dispute rate per group
- Support tickets on "wrong balance"
- 30-day retention for groups using explanation panel

**Why:** In expense sharing, trust is retention. Math transparency = lower churn than prettier UI

## Positioning Statement
**"Splitwise helps you track shared expenses. Even Us Up helps your group finish them."**

Own fast, fair, trusted *settlement* and you get both the switch reason and the stickiness.
