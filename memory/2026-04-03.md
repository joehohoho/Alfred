## Idle Activity: Self-Improvement (18:49 ADT)

**Problem Identified:** Brave Search API returning 429 (rate limit exceeded) errors in gateway.err.log, happening ~every 1-2 hours on free tier.

**Root Cause:** Rate limiter enforces 1 search/min but doesn't retry on 429 errors—just fails immediately. During high activity periods, Brave free tier (1 req/min, 2000/month) gets exceeded.

**Solution Implemented:** Enhanced `scripts/web-search-rate-limiter.sh`:
- Added 429 error detection
- Exponential backoff (2s → 4s → 8s, max 30s)
- Up to 3 retries before failing
- Tracks `last_429_unix` to avoid immediate re-hammering after hitting limit
- Preserves existing rate-limit enforcement (1 req/min baseline)

**Files Changed:**
- `scripts/web-search-rate-limiter.sh` (+83 lines, improved error handling)

**Impact:** Next time gateway hits 429, script will auto-retry instead of immediately failing, reducing noisy errors in logs and allowing legitimate searches to complete on second/third attempt.

**Test:** Verified script syntax and git commit. Runtime testing happens when natural 429 occurs (no manual trigger needed—graceful degradation).
