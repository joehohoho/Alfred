## [idle:improve-self] HAL Timeout Dedup Bug Fix (00:59-01:05)

**Issue Found:** When HAL gateway times out, the fallback to Alfred dispatch was blocked by the dedup tracker. The CoinUsUp card was stuck in_progress with repeated "Already dispatched to Alfred within 1h" logs despite HAL being offline for 30+ minutes.

**Root Cause:** `dispatch_to_alfred()` checks a dedup tracker to avoid re-sending every 15 min. When called as a HAL fallback, this caused the card to be silently dropped instead of being dispatched.

**Fix:** Added `from_hal_failure` flag parameter to `dispatch_to_alfred()`. When true (HAL timeout case), skip the dedup check so the card can be immediately escalated to Alfred. This prevents queue lockup when HAL is offline.

**Files Modified:**
- `scripts/alfred-work-executor.sh`: dispatch_to_alfred() logic + caller site

**Tested:** Script runs successfully, no errors.

**Impact:** Cards will now execute on Alfred when HAL is unavailable instead of being stuck.
