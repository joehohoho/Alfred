## 🎓 Learning Notes

**Infrastructure Observability:**
- Service health dashboards prevent silent failures
- 15-min polling is aggressive enough for critical services
- Alert deduplication prevents notification fatigue

**System Monitoring Best Practices:**
- Centralized health check (vs. multiple scattered tools)
- JSON + markdown dual output (machine + human readable)
- Fail-open on network issues (network errors != service down)
- Alert history for trend analysis

**HAL Gateway Issues:**
- WebSocket connections are sensitive to auth/circuit breaker state
- 117 consecutive failures can trigger circuit breaker
- Network reachability ≠ application availability
- Requires deep diagnostics (port test, handshake analysis, logs)
