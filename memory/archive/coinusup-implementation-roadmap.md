## Phase 3A: CoinUsUp Feature Audit (Required Before Production)

Before we write content promoting CoinUsUp features, we need to confirm CoinUsUp actually has these features:

### Feature Checklist (Critical Path)

**Donation Tracking (Core):**
- [ ] Can CoinUsUp capture donation date, amount, donor, method?
- [ ] Can users create custom fields (restricted vs. unrestricted, recurring)?
- [ ] Can users generate reports (monthly donations, lifetime giving, trend analysis)?
- [ ] Can users export donation data (CSV, PDF)?
- **Why:** All content assumes this works. If limited, messaging changes.

**Volunteer Management:**
- [ ] Can CoinUsUp track volunteer hours and assignments?
- [ ] Can users set volunteer schedules/shifts?
- [ ] Can users generate reports (total hours by volunteer, by program)?
- [ ] Can users send automated reminders (upcoming shifts, thank-yous)?
- **Why:** Volunteer management is 40% of the content calendar. Need confirmation this works.

**Grant Management:**
- [ ] Can CoinUsUp track grants (deadline, amount, status)?
- [ ] Can users add custom fields (funder, reporting requirements)?
- [ ] Can users set automated reminders (30 days before deadline)?
- **Why:** Grant content assumes this is possible. If limited, we focus on "grant tracking best practices" instead of "grant tracking in CoinUsUp."

**Email/Communication:**
- [ ] Can CoinUsUp send bulk emails to donor/volunteer segments?
- [ ] Can users create email templates?
- [ ] Can users track opens/clicks?
- **Why:** Content funnel needs email follow-up capability.

**Reporting & Insights:**
- [ ] Can CoinUsUp generate custom reports?
- [ ] Can users export data to spreadsheet?
- [ ] Can users view trends over time (increasing/flat/declining giving)?
- **Why:** Educational content promises "use your data to improve fundraising." Need reports to prove value.

**User Management:**
- [ ] How many users allowed on free tier? (Current: 2)
- [ ] Can nonprofits add more for a fee?
- **Why:** Affects positioning for small teams.

## Phase 3B: Platform Decision (Hosting/Blogging)

The content hub needs a home. Here are four options:

### Option 1: CoinUsUp Native Blog (If Built In)
**Pros:**
- Unified experience (CoinUsUp + blog in one place)
- Simplest for CTAs to trial
- Users already on site

**Cons:**
- Requires CoinUsUp to have blogging capability
- SEO depends on CoinUsUp's domain authority

**Effort:** 0 setup (if CoinUsUp has blog feature)

**Cost:** $0 (assuming included in platform)

---

### Option 2: Substack (Easiest, Limited SEO)
**Pros:**
- Fastest setup (30 min)
- Built-in email list
- Free plan available
- No maintenance

**Cons:**
- Limited SEO (Substack domains are lower authority)
- Harder to build a "hub" (linear newsletter vs. structured site)
- Limited customization

**Effort:** 2-4 hours setup

**Cost:** Free or $120/year (for unlimited subscribers)

**Best for:** Testing content quickly, building email list early

---

### Option 3: Ghost (Balanced)
**Pros:**
- Built for blogging (excellent SEO)
- Modern design
- Email list integrated
- Good documentation

**Cons:**
- Requires some technical setup
- $25+/month hosting cost
- More maintenance than Substack

**Effort:** 4-8 hours setup

**Cost:** $25-50/month hosting + domain ($12/year)

**Best for:** Long-term content hub with strong SEO needs

---

### Option 4: WordPress (Most Flexible, Most Work)
**Pros:**
- Unlimited customization
- Strongest SEO plugins (Yoast, Rank Math)
- Largest ecosystem
- Can self-host (lower cost)

**Cons:**
- Highest maintenance burden
- Security requires constant updates
- Steeper learning curve

**Effort:** 8-16 hours setup

**Cost:** $5-20/month hosting + domain ($12/year) + plugins ($100-300/year)

**Best for:** Organizations with IT support or outsourced maintenance

---

### Recommendation for Joe

**Start with:** Ghost or WordPress on a subdomain (e.g., tools.coinusup.com)

**Why:**
- Builds authority on CoinUsUp's main domain
- Better SEO than Substack
- Easier than building native CoinUsUp blog
- Separates blog from product (cleaner UX)

**Setup time:** 4-8 hours (hire if needed, cost $200-500)

## Risk Mitigation & Success Factors

### Risks & Mitigations

**Risk 1: Low Search Volume for Chosen Keywords**
- Mitigation: Start with verified high-volume keywords (free volunteer management, nonprofit CRM). Monitor rankings in weeks 1-4. Pivot if needed.

**Risk 2: CoinUsUp Feature Gaps**
- Mitigation: Feature audit before production. If features missing, adjust content to emphasize "best practices" over "how to in CoinUsUp."

**Risk 3: Poor Conversion from Organic Traffic**
- Mitigation: A/B test CTAs, landing pages, trial flow. Monitor conversion rates. Optimize top performers.

**Risk 4: Content Underperformance**
- Mitigation: Publish fastest-to-rank pieces first (how-to guides, templates). Measure traffic/rankings in weeks 1-4 before scaling.

---

### Success Factors (Do These)

1. **Publish consistently** — 2-3 pieces per week, not sporadic
2. **Optimize for conversions** — Don't just write; measure trial signups per piece
3. **Promote** — Share on nonprofit forums, Reddit, LinkedIn, email lists
4. **Build backlinks** — Reach out to nonprofit resource sites for links (boosts SEO)
5. **Update top performers** — Refresh highest-traffic pieces every 6 months
6. **Monitor rankings** — Use GSC + Ahrefs to track which keywords you're ranking for
7. **Iterate** — Test, measure, improve. Don't set-and-forget
